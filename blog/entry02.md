# Entry 2
##### 11/16/26

#### Summary 
Through the Google search "Fiction writing apps", the technologies I found were software such as <a href="https://www.literatureandlatte.com/scrivener/overview">Scrivener</a>, and <a href="https://www.novelist.app/">Novelist</a>. These apps offer various features, including ones that allow the user to move around plot points and that let you make books up to no limit. I also discovered written sources like <a href= "https://j-nelson.net/2017/04/computer-programming-writing-fiction-iterative-processes/">Computer programming & writing fiction: Iterative processes | Jim Nelson</a>, which provided a thoughtful perspective on the overlaps in the process of coding and in writing. 

I later revised my Google search to "Fiction writing technology" to obtain more diverse results. One of the displayed websites was <a href="https://kadavy.net/distraction-free-writing-devices/">Kadavy</a>, which listed many different hardware. The first object listed was the **typewriter** which has both mechanical and electrical types. Both types aid in minimizing distractions, although the <a href="https://i5.walmartimages.com/seo/Nakajima-USA-WPT-160-Electronic-Portable-Typewriter-with-Display-White_7d5abae2-0ca2-491b-a060-c643ed00b7e4.3130eb924392fc9b2a9ac53da1ebd7db.jpeg">electrical typewriter</a> in particular requires less finger strength, and uses an electrical motor to power the typing stroke, so it needs to be plugged into an outlet with the correct voltage. Another hardware discussed was the <a href="https://m.media-amazon.com/images/I/71IVE7DcX-L.jpg">AlphaSmart</a>, a portable word processor built solely for raw text entry. Anything written in the AlphaSmart can be transferred to a computer or tablet using a USB cable, and it requires just three AA batteries at a time. 

#### Organization
Categories other than software and hardware that I considered were difficulty level and price. However, I realized that sorting by difficulty wasn't a good idea since most of the technology I found had similar features, meaning that how challenging they were to use is too subjective. This led to the price being the final organization for my research because it's objective.
