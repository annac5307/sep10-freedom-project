# Content
Topic: **Fiction Writing**

## Overview/Introduction/Context
* Fiction writing is a type of literary creation in which the crafted stories are based on non-factual characters, settings, and/or events. 
* With the rise of technology, it's vital that authors know how to utilize the provided tools. 

## Categories 

##### Lowest to Highest Prices
Google search: Fiction Writing apps

The first software I viewed was <a href="https://www.novelist.app/">novelist</a>

Google search: Fiction writing technology

 * One of the results was <a href="https://kadavy.net/distraction-free-writing-devices/">Kadavy</a>, which named various hardware
 * A listed option was the **Alphasmart**
 * [Alphasmart Link](https://m.media-amazon.com/images/I/71IVE7DcX-L.jpg)
 * Portable word processor (single-purpose gadget built for raw text entry)
 * stores eight separate files, so you can easily switch between projects
 * Writing can be transferred to a computer or tablet via a USB cable
 * Works for months on three AA batteries
 * Available on Amazon for around $80
     
The next app I viewed was <a href="https://www.literatureandlatte.com/scrivener/overview">Scrivener</a>
<img height="87" src="https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcSWJjps9fpCBUtIc8h5Xuk_yLKLnRQXTAH8X8cnJbAkvoTgcaI9UuLMy2c9&s=10"/>
  
 * $59.99 for macOS or Windows, $23.99 for IOS, $95.99 bundle for both macOs and Windows
 * Costs $121.93 to buy all three platforms (macOs, Windows, and IOS)
 * Allows users a 30 day free trial (only applicable for macOS and Window versions)
 * Digital binder that stores manuscripts, world-building notes, character sketches, etc
 * Split-Screen allows multiple documents or reference notes to be opened simultaneously
 * Composition Mode hides computer's desktop and toolbars for maximum writing space
 * Snapshots saves a backup copy of a scene or chapters before it's rewritten, meaning you can compare or revert text anytime
 * Corkboard feature lays down virtual index cards of each scene so the plot can be reordered with simple drags and drops

I also viewed <a href="https://www.atticus.io/">Atticus</a>
<img height="175" src="https://thewritepractice.com/wp-content/uploads/2023/10/miniLogo.f0799810.png"/>
* One-time cost of $147 
* Usable on any computer
* Collaboration features where you can assign others specific roles, such as the Co-writer and the Beta Reader.
* Automatic saving and cloud backup
* Wide variety of text and styling tools (ex: block-quotes,interior images, hyperlinks)
* 17 chapter templates and a custom template builder
* Formats the book
* Goal and habit settings to motivate the user
